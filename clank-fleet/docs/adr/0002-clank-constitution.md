# ADR 0002: Clank Constitution and defensible-belief contracts

Status: Accepted

Repeated cross-Clank failures showed that green runtime health can coexist with
poor recall, stale discoveries, identity errors, unsafe zero/removal inference,
delivery ambiguity, and duplicate writers. Official-only coverage also misses
specialist early signals. These are reusable architecture lessons, not domain
folklore.

Unified therefore standardises uncertainty, provenance, stage-level pipeline
records, source semantics, delivery accounting, execution provenance, and
immutable evidence with versioned interpretation. Domain Clanks retain source
zero semantics, identity, novelty, state transitions, and event meaning.

The constitution deliberately does not implement ClankOps intelligence,
Diagnostic investigation, autonomous remediation, or a universal source score.
Those consumers may reason over the declared facts later. Legacy Clanks may use
read-only adapters and advertise partial or unsupported capability.

The constitution also adopts the shared human-QC contract: reviewable findings
use the four dispositions `USEFUL`, `NOT USEFUL`, `FALSE POSITIVE`, and `OUT OF
STOCK` with durable provenance and append-only history. This records operator
judgement without making it authoritative domain truth; see ADR 0003.
